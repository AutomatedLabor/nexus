# 12 — Standard Library

> **Status:** 🧪 Experimental
> **Subsystem:** `aether/stdlib/*`
> **Spec version:** 0.1

This section enumerates the **standard library** of Aether 0.1.
The stdlib is deliberately *curated*: ten modules, plus the
`core::prelude` and the trait ecosystem in `core::*`. Each
module lives in its own directory under `aether/stdlib/` and
exposes a small, documented surface. The exact function
signatures are reference documentation (generated by
`aether docgen`); this section fixes the *names*, *types*, and
*semantics contracts* that conformant implementations MUST
provide.

list only the module surface.

## 2. Conventions

- Function names are `snake_case`; type names are `PascalCase`;
  constants are `UPPER_SNAKE`.
- Each module re-exports a curated subset of names; deep paths
  (`std::collections::map::Entry`) are available but not re-exported.
- Methods on primitive types are inherent methods; methods on
  collection types are trait methods where possible (so that
  `List<T>::iter()` and `Vec<T>::iter()` share the `Iterator`
  trait method).
- All stdlib functions that can fail return `Result`; none panic
  except where the language spec mandates it (e.g. integer
  overflow in debug, divide-by-zero).
- The stdlib is *feature-flag-free* in 0.1: every module is always
  available, regardless of target. Platform-specific
  implementations (e.g. `std::io` on `wasm32`) provide a *partial*
  surface and clearly document what is unavailable.

## 3. `core::prelude`

Auto-imported into every module unless `#![no_prelude]` is set.
The prelude exports:

- Types: `Bool`, `Int`, `Uint`, `Float`, `Char`, `String`, `Bytes`,
  `Unit`, `Option`, `Result`, `List`, `Map`, `Set`, `Box`, `Rc`,
  `Arc`, `Future`, `Channel`, `JoinHandle`.
- Constructors: `Some`, `None`, `Ok`, `Err`.
- Traits: `Display`, `Debug`, `Clone`, `Eq`, `Ord`, `Hash`,
  `Default`, `Iterator`, `IntoIterator`, `FromIterator`,
  `From`, `Into`, `Send`, `Sync`, `Sized`.
- Macros: `panic!`, `todo!`, `unreachable!`, `assert!`,
  `assert_eq!`, `assert_ne!`, `format!`, `println!`,
  `eprintln!`, `print!`, `dbg!`, `select!`.
- Operators/keywords surfaced as values: `await`, `spawn`.

## 4. `core::option`, `core::result`

```aether
enum Option<T> { None, Some(T) }
enum Result<T, E> { Ok(T), Err(E) }
```

Each provides:

- `is_some`, `is_none`, `is_ok`, `is_err` — `Bool` predicates.
- `unwrap`, `unwrap_or(default)`, `unwrap_or_else(f)` — extract
  or panic/default.
- `map(f)`, `and_then(f)`, `or(other)`, `or_else(f)` — monadic
  combinators.
- `?` operator semantics (§08 §2).
- `ok()`, `err()` — cross-conversion between `Option` and
  `Result`.

## 5. `core::iter`

The `Iterator` trait:

```aether
trait Iterator {
    type Item;
    fn next(&mut self) -> Option<Self::Item>;

    // provided:
    fn map<U>(self, f: impl Fn(Self::Item) -> U) -> Map<Self, F>;
    fn filter<P: Fn(&Self::Item) -> Bool>(self, p: P) -> Filter<Self, P>;
    fn fold<B>(self, init: B, f: impl Fn(B, Self::Item) -> B) -> B;
    fn collect<C: FromIterator<Self::Item>>(self) -> C;
    fn for_each<F: Fn(Self::Item)>(self, f: F);
    fn take(self, n: Int) -> Take<Self>;
    fn skip(self, n: Int) -> Skip<Self>;
    fn enumerate(self) -> Enumerate<Self>;
    fn zip<U: Iterator>(self, other: U) -> Zip<Self, U>;
    fn chain<U: Iterator<Item = Self::Item>>(self, other: U) -> Chain<Self, U>;
    fn count(self) -> Int;
    fn any<P: Fn(Self::Item) -> Bool>(self, p: P) -> Bool;
    fn all<P: Fn(Self::Item) -> Bool>(self, p: P) -> Bool;
    fn find<P: Fn(&Self::Item) -> Bool>(self, p: P) -> Option<Self::Item>;
    fn nth(self, n: Int) -> Option<Self::Item>;
    fn min(self) -> Option<Self::Item>         where Self::Item: Ord;
    fn max(self) -> Option<Self::Item>         where Self::Item: Ord;
    fn sum<S>(self) -> S                       where Self::Item: Add<S, Output = S> + Default;
    fn product<S>(self) -> S                   where Self::Item: Mul<S, Output = S> + Default;
}
```

The list above is the minimum required surface. Implementations
MAY provide more adapters; any added adapter MUST be documented in
the generated reference and is part of the stability promise.

## 7. `std::string`

The `String` type is a growable UTF-8 string:

- `String::new()`, `String::with_capacity(n)`, `String::from(s)`,
  `String::from_utf8(bytes) -> Result<String, Utf8Error>`.
- `s.len()`, `s.is_empty()`, `s.capacity()`, `s.clear()`.
- `s.push(ch)`, `s.push_str(s2)`, `s.insert(idx, ch)`,
  `s.remove(idx)`.
- `s.bytes()`, `s.chars()`, `s.graphemes()`,
  `s.lines()`, `s.words()`, `s.split(sep)`,
  `s.split_whitespace()`.
- `s.to_lowercase()`, `s.to_uppercase()`,
  `s.trim()`, `s.trim_start()`, `s.trim_end()`,
  `s.replace(from, to)`,
  `s.repeat(n)`, `s.reverse()`.
- `s.starts_with(p)`, `s.ends_with(p)`, `s.contains(p)`,
  `s.find(p) -> Option<Int>`, `s.rfind(p) -> Option<Int>`.
- `s.parse<T: FromStr>() -> Result<T, ParseError>`.
- `s.as_bytes() -> &Bytes`, `s.as_str() -> &str`.

`&str` is a slice reference to a `String` (or string literal). It
implements `Display`, `Eq`, `Ord`, `Hash`.

## 8. `std::bytes`

- `Bytes::new()`, `Bytes::with_capacity(n)`,
  `Bytes::from(vec)`, `Bytes::from_str(s)`.
- `b.len()`, `b.is_empty()`, `b.push(byte)`, `b.extend(other)`.
- `b[i]` (returns `u8`), `b[i..j]` (returns `Bytes` slice).
- `b.copy_to_slice(dst)`, `b.copy_from_slice(src)`.
- `b.iter() -> Iterator<u8>`, `b.chunks(n)`, `b.windows(n)`.

## 9. `std::text`

Unicode-aware text operations:

- `graphemes(s) -> Iterator<String>` — grapheme cluster iteration
  (UAX #29).
- `normalize(s, form: NormalForm) -> String` — NFC, NFD, NFKC,
  NFKD (UAX #15).
- `collate(a, b, locale: Locale) -> Ordering` — Unicode collation
  (UAX #10).
- `width(s) -> Int` — display width (East Asian Wide/FullWidth
  rules).
- `category(ch) -> UnicodeCategory` — general category.
- `is_alphabetic`, `is_numeric`, `is_whitespace`, `is_control`,
  `is_punctuation` — per-code-point predicates.

## 10. `std::regex`

A small, fast regular expression engine. The syntax is a subset
of PCRE: character classes, alternation, repetition (`*`, `+`,
`?`, `{n,m}`), groups, anchors, lookahead (no backreferences, no
lookbehind in 0.1).

```aether
let re = Regex::new(r"(\d{4})-(\d{2})-(\d{2})")?;
let m = re.captures("2026-11-11")?;
let year  = m.get(1);     // "2026"
let month = m.get(2);
let day   = m.get(3);
```

API:

- `Regex::new(pattern: String) -> Result<Regex, RegexError>`.
- `Regex::is_match(s: &str) -> Bool`.
- `Regex::find(s: &str) -> Option<Match>`.
- `Regex::find_all(s: &str) -> Iterator<Match>`.
- `Regex::captures(s: &str) -> Option<Captures>`.
- `Regex::captures_all(s: &str) -> Iterator<Captures>`.
- `Regex::replace(s: &str, replacement: &str) -> String`.
- `Regex::replace_all(s: &str, replacement: &str) -> String`.
- `Regex::split(s: &str) -> Iterator<String>`.

## 11. `std::encoding`

| Item | API |
|---|---|
| `base64::encode(bytes) -> String` | standard base64 |
| `base64::decode(s) -> Result<Bytes, DecodeError>` | strict |
| `base64::encode_urlsafe`, `decode_urlsafe` | URL-safe alphabet |
| `hex::encode(bytes) -> String`, `hex::decode(s) -> Result<Bytes, _>` | lower-case |
| `json::encode(value: &dyn Encode) -> String` | |
| `json::decode<T: Decode>(s: &str) -> Result<T, JsonError>` | |
| `msgpack::encode`, `msgpack::decode` | binary |
| `utf8::from_bytes(bytes) -> Result<String, Utf8Error>` | |
| `utf8::to_bytes(s: &str) -> Bytes` | |

`Encode` and `Decode` traits are derivable via `#[derive(Encode,
Decode)]`. The JSON encoder emits compact JSON by default;
`json::encode_pretty(value, indent)` emits indented JSON.

## 12. `std::datetime`

| Item | Purpose |
|---|---|
| `Instant`  | monotonic time point; `Instant::now()`, `Instant::elapsed_since(t)` |
| `Duration` | `Duration::from_secs(n)`, `from_millis`, `from_micros`, `from_nanos`, `+`, `-`, comparison |
| `Date`     | civil calendar date (year, month, day) |
| `Time`     | civil time of day (hour, minute, second, nanos) |
| `DateTime` | `Date + Time` in a `TimeZone` (UTC by default) |
| `TimeZone` | IANA timezone (`"America/New_York"`, etc.) |
| `Format`   | strftime-style format strings (`"%Y-%m-%d"`) |

Operations include parsing (`DateTime::parse`), formatting
(`dt.format("%c")`), arithmetic (`dt + Duration`), rounding
(`dt.round(Duration)`), and comparison. The implementation uses
the host's ICU when available; otherwise a bundled tz database
shipped with `aether/stdlib/datetime/tzdata/`.

## 13. `std::collections`

| Type | Notes |
|---|---|
| `List<T>` | growable array, like `Vec<T>` in Rust |
| `Vec<T>`  | alias for `List<T>` |
| `Deque<T>`| double-ended queue |
| `Map<K, V>` | hash map (`K: Hash + Eq`) |
| `Set<T>`  | hash set (`T: Hash + Eq`) |
| `BTreeMap<K, V>` | sorted map (`K: Ord`) |
| `BTreeSet<T>` | sorted set (`T: Ord`) |
| `Rc<T>`   | single-threaded reference count |
| `Arc<T>`  | atomic reference count (multi-threaded runtime) |
| `Box<T>`  | heap-allocated, single owner |
| `Weak<T>` | non-owning reference |
| `Cell<T>`, `RefCell<T>` | interior mutability, single-threaded |
| `Mutex<T>`, `RwLock<T>` | interior mutability, multi-threaded |
| `Lazy<T>` | one-time initialization |

Each collection provides:

- Construction: `new`, `with_capacity`, `from_iter`.
- Inspection: `len`, `is_empty`, `contains`, `get`, `iter`,
  `iter_mut`.
- Mutation: `insert`, `remove`, `clear`, `extend`, `retain`.
- `Entry` API on `Map`/`BTreeMap` for in-place updates.

## 14. `std::io`

```aether
trait Read  { fn read(&mut self, buf: &mut [u8]) -> Result<Int, IoError>; }
trait Write { fn write(&mut self, buf: &[u8])    -> Result<Int, IoError>;
              fn flush(&mut self) -> Result<(), IoError>; }

struct File { /* ... */ }
impl File {
    fn open(path: &str) -> Result<File, IoError>;
    fn create(path: &str) -> Result<File, IoError>;
    fn read_to_string(&mut self) -> Result<String, IoError>;
    fn write_all(&mut self, buf: &[u8]) -> Result<(), IoError>;
    fn close(&mut self);
}

let stdin  = io::stdin();
let stdout = io::stdout();
let stderr = io::stderr();
```

Buffered readers/writers are provided:

- `BufReader::new(r)`, `BufWriter::new(w)`.
- `Lines<B: BufRead> = Iterator<String>`.

Platform availability: `File` is unavailable on `wasm32` (use the
host's filesystem API via §14). `stdin`/`stdout`/`stderr` are
available everywhere; on `wasm32` they default to no-op writes
and EOF reads.

## 15. `std::async`

```aether
trait Future {
    type Output;
    fn poll(&mut self, ctx: &mut Task) -> Poll<Self::Output>;
}
enum Poll<T> { Ready(T), Pending }

struct Channel<T> { /* ... */ }
impl<T> Channel<T> {
    fn unbounded() -> (Sender<T>, Receiver<T>);
    fn bounded(capacity: Int) -> (Sender<T>, Receiver<T>);
}

struct JoinHandle<T> { /* ... */ }
impl<T> JoinHandle<T> {
    fn cancel(&self);
    fn is_finished(&self) -> Bool;
}

struct Timer { /* ... */ }
impl Timer {
    fn after(d: Duration) -> Timer;
    fn at(instant: Instant) -> Timer;
}

struct Runtime { /* ... */ }
impl Runtime {
    fn new(config: RuntimeConfig) -> Runtime;
    fn spawn<F: Future>(&self, f: F) -> JoinHandle<F::Output>;
    fn block_on<F: Future>(&self, f: F) -> F::Output;
    fn shutdown(self);
}
```

`select!` is a built-in macro (§07 §4.5).
`Task::current()` returns the current task; `Task::yield_`
cooperatively yields.

## 16. `std::crypto`

A *small* but *audited* crypto module. Implementations MUST
constant-time-compare secrets and MUST reject side-channel
patterns at the API level. The module is sized to support
common applications; advanced crypto is out of scope for 0.1.

| Item | API |
|---|---|
| `hash::Sha256`, `Sha512`, `Sha3_256`, `Blake3` | `fn new() -> Self; fn update(&mut self, &[u8]); fn finalize(self) -> Bytes` |
| `hash::Hasher` trait | unify the above |
| `hmac::Hmac<H: Hasher>` | HMAC over any hasher |
| `mac::Poly1305` | one-time authentication |
| `aead::AesGcm`, `ChaCha20Poly1305` | `fn new(key: &Bytes) -> Self; fn encrypt(&mut self, nonce, aad, msg) -> Bytes; fn decrypt(...) -> Result<Bytes, CryptoError>` |
| `kdf::Pbkdf2`, `Argon2id`, `Hkdf` | password / key derivation |
| `rand::ChaCha20Rng` | CSPRNG |
| `rand::fill(bytes: &mut [u8])` | fill with random bytes |
| `rand::random<T>() -> T` | uniform random for `T: Uniform` |
| `constant_time::eq(a: &[u8], b: &[u8]) -> Bool` | constant-time equality |

`std::crypto` is feature-flagged behind `--features crypto-tls`
only for the TLS *transport*; the primitives above are always
available. The TLS module itself is in a separate package
(`async-tls`) for size and auditability.

## 17. Conformance

A conformant stdlib MUST:

- provide every item listed above with the documented signature
  and semantics,
- be importable from any module as `use std::<mod>::<item>;`,
- behave identically across all supported targets except where
  this section explicitly marks an item as
  platform-unavailable,
- include the source for every module under
  `aether/stdlib/<mod>/`, organized so that `aether docgen` can
  produce a complete reference.

The stdlib is permitted to expose *additional* APIs beyond this
list; such additions are stable within a minor version and may be
promoted to required APIs in future minor versions.
